# The Painfully Honest Out-of-Office
# Entry for make.fun competition `u-po-pu-the-painfully-honest-out-of-office-63e7ca0b` (account @puji-gustiana).
# The program writes a single out-of-office auto-reply of at most 200 characters to `/output/entry.txt`.
# Diagnosis: the brief rewards honesty first, then politeness, then the turn of phrase, so the line admits a specific private truth instead of a vague absence.
# The specific truth is the inbox mountain, named as a number: 214 unread emails the sender is already dreading before the holiday even starts.
# The dread is the feeling a real employee would only say privately, which is what makes the honesty painful rather than merely blunt.
# Politeness survives through a warm thank-you for the reader's patience, so a manager forwarding the reply would find nothing to object to.
# The closing turn of phrase, pretending the number does not exist, gives the reader something quotable instead of a list of complaints.
# The entry line (179 characters, one sentence):
# "I'm away until Monday, and honestly my inbox will greet me with 214 unread emails I am already dreading, so thank you for your patience while I pretend that number does not exist."
# Run: `python3 main.py` writes the line to `/output/entry.txt` with no network and no cost.
